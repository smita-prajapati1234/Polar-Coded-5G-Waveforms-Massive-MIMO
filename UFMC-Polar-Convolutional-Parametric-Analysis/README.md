# Parametric Analysis of UFMC with 5G NR Polar and Convolutional Codes in a Massive MIMO System

## Overview

This project presents MATLAB-based parametric analysis of a UFMC-based Massive MIMO system using 5G NR Polar and convolutional channel coding.

The study evaluates the impact of key system parameters on BER and SNR performance and compares Polar-coded and convolutional-coded UFMC systems.

## Publication

**Authors:** S. Prajapati, D. Jain, and N. Kapil  
**Journal:** ITEGAM-JETIA  
**Volume:** 11, Issue 51, pp. 157–163, 2025  
**DOI:** https://doi.org/10.5935/jetia.v11i51.1345

## Research Areas

- UFMC
- 5G NR Polar Coding
- Convolutional Coding
- Massive MIMO
- BER and SNR Analysis
- 5G/6G Wireless Communication

## MATLAB Code

The MATLAB files included in this folder support the simulation and parametric analysis presented in the published research work.
